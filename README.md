# Exploratory Data Analysis (EDA) Project

## Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to discover patterns, trends, and relationships among different passenger attributes.

## Objectives

* Analyze dataset characteristics
* Generate statistical summaries
* Identify correlations between variables
* Visualize trends using charts and graphs
* Extract meaningful insights from data

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Visualizations

1. Correlation Heatmap
2. Age Distribution Histogram
3. Gender vs Survival
4. Passenger Class vs Survival
5. Fare Distribution Boxplot

## Key Insights

* Female passengers had higher survival rates.
* First-class passengers were more likely to survive.
* Most passengers were young adults.
* Fare and passenger class were important influencing factors.

## Conclusion

The EDA process revealed significant patterns and relationships within the Titanic dataset, providing valuable insights into factors affecting passenger survival.
